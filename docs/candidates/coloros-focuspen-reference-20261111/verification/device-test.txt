Soft restart:
The standalone init bridge originally survived system_server restart with dead Bluetooth handles.
The new bridge links to system-server death, exits, and is restarted by init with fresh handles.
Bridge PID changed automatically after the user-triggered soft restart and restored real HID state=2.
Unknown Bluetooth names and empty magnetic MAC are recovered from matching real input devices.

Final incremental battery changes:
Each provider update carries focuspen_mac, validates the source still belongs to the current pen,
and updates only that device's SDK battery list. Cross-pen old values are not reused.
Undocked battery refresh uses the Bluetooth stack's measured level; no extra GATT connection is held open.
Invalid/unknown levels are omitted rather than replaced with a made-up value.
Actual percentage depletion / swapping a second physical pen was not forced during this session.
