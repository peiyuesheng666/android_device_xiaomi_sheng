# 手写笔接口参考

外部手写笔方案用于理解配件身份、连接顺序和界面行为。sheng 的应用、服务和控制器适配在本设备树独立实现；原厂协议以本机触摸控制器和配件描述符为准。

| 接口 | sheng 的处理 |
| --- | --- |
| 配件身份 | 校验完整 Bluetooth PnP、来源、vendor 与 product，分别选择普通 Focus Pen 和 Pro。 |
| 控制器连接 | 使用本机 520 字节 `common_data` ABI；其他设备的三整数 ioctl 参数不能直接使用。 |
| Pro 压力 | 将匹配描述符的 HID report 5 原始压力送入 THP operation 7、mode 1088。 |
| 压力范围 | 按报告描述符和 NVT 输入范围处理，不套用其他笔的固定上限。 |
| 真实笔输入 | 保留 NVT 笔节点，按硬件身份管理配件产生的键盘、鼠标及消费控制节点。 |
| 界面与充电 | 由本机 product 应用显示连接、电量、充电提示和设置，不依赖其他系统的配件管理服务。 |
| 显示协调 | 使用独立 Binder token 请求适合笔输入的显示速率，释放后撤销该请求。 |

参考文件的来源与哈希保存在对应 JSON 中。外部目录的部署脚本和二进制不属于本设备树的构建入口。实现位置见 [手写笔接入](FOCUS_PEN_INTEGRATION.md)。
