# 手写笔设置

`ShengPenSettings` 是设置中“已连接的设备”的手写笔入口，安装到 product。页面展示笔的型号、图标、连接、电量、充电状态和固件信息，并提供状态刷新及蓝牙管理入口。

信息异步获取，页面保留稳定的布局和占位区域；更新数据时不重新创建整个页面。返回图标与笔尖资源使用统一的几何中心。

电量必须是当前设备的有效读数。已知停止充电时显示“未充电”，取下后显示“未充电 · 已取下”；缺少可信数据时不伪造电量或充电状态。

吸附提示由常驻服务提供：型号在上方，配有笔图，下方为电量条和百分比。提示带出现及退出动画，仅通过上滑收起，不设置关闭按钮，也不创建通知栏条目。收起提示不改变实际充电或连接状态。

应用入口包含面向旧 API 的降级页面，现代功能通过独立入口加载。代码压缩规则保留反射使用的构造与方法，资源按 API 能力提供对应形式。常驻服务与手写输入见 [Focus Pen 接入](FOCUS_PEN_INTEGRATION.md)。
