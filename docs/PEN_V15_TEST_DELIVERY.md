# 手写笔配套测试包 v15（2026-11-17）

这是用于反馈测试的候选包，不是完整 ROM，也不表示普通笔压感或 Pro 偶发停止移动已修复。
没有一键安装器；没有向当前 USB 平板刷写分区。

## 文件

- `ShengStylus.apk`：手写笔服务应用，v15 / 1.14-test。
- `ShengPenSettings.apk`：手写笔设置应用，v10 / 1.9-test。
- `vendor.img`：配套原生服务、启动配置、四种笔设备的精确键位配置与权限策略。
- `odm.img`：与本次 vendor 对应的预编译 SELinux 策略；保留原 ODM 的其他内容。
- `vbmeta.img`：仅更新 vendor / ODM 校验描述符，保留原签名公钥、回滚值与验证标志。
- `verification.json`、`SHA256SUMS`：基线、构建验证记录和文件校验值。

## 底包与安装边界

仅面向本项目 `PixelOS_sheng-17.0-20261117-full` 的 sheng 平板。
不能凭“同一天的版本”判断兼容：须核对 `verification.json` 中 baseline，尤其 system、system_ext、product、原 vbmeta。
如果反馈机仍是其他上午测试版，或者修改过这些系统分区，先确认它的完整底包来源，不要直接刷本包。
该包不包含更换底包所需的所有分区，不能作为从其他版本升级系统的通用刷机包。

vendor 与 ODM 必须配套。原底包优先加载 ODM 的预编译策略，单换 vendor 会继续使用旧策略。
vbmeta 也必须与本次分区匹配；不得额外关闭 AVB / verity、清空 vbmeta 或使用 permissive 绕过权限。
分区镜像由熟悉动态分区操作的人在确认底包及回退镜像后手动更新，vendor / ODM 使用 fastbootd，不是普通 bootloader fastboot。
vendor.img / odm.img 是标准 Android sparse 镜像；不能把 sparse 文件直接 dd 到块设备。
不更换 boot、init_boot、vendor_boot、内核或 userdata，不要求清数据。
刷写前另行保留反馈机原 vendor、ODM、vbmeta 和用户数据；本候选包不自带回退镜像。

两个 APK 是应用本体，不是安装器。配套分区更新后，覆盖安装两个 APK，再重启。
命令行覆盖安装可用 `adb install -r ShengStylus.apk` 与 `adb install -r ShengPenSettings.apk`；也可直接打开 APK 覆盖安装。
依赖底包已预装同签名的系统应用及其授权，不能当作通用第三方应用在其他系统上安装。
若提示签名不一致、版本降级或安装失败，保留错误信息，不要卸载系统服务、清除数据或强行绕过签名。
重启后吸附笔一次再取下；旧的一键安装器或 root 覆盖模块若还在替换服务，应先确认其是否仍生效，不能让旧服务覆盖本次镜像。

## 反馈重点

普通笔：先测试连续书写和轻重压线条，再测试三个键的截图、菜单、按住第三键移动鼠标及松开退出。
同时检查输入框不自动输入加号、吸附再取下和息屏唤醒后仍可写；任何冻结立即停止重复尝试并保留日志。
普通笔没有套用 Pro 的握压点击逻辑，不能用 Pro 的测试动作判断普通笔按键失效。

Pro：菜单开启鼠标、握压单击、按住握压拖动、松开释放、双击笔身退出；笔身上下滑固定为上下滚动。
如握压拖动后方向停止但点击仍有效，仍属于未闭环问题，请记录动作和时间，区分是否重新进入模式才恢复。
双击退出后连接着的触摸板仍能控制系统光标，属于正常共用光标行为。
当前 USB 平板曾设置的系统鼠标速度 -2 没有自动写入本包；反馈机不会继承这项临时设置。

## 已做与未做

已通过现有普通笔三份日志的压力回放和相关软件测试；镜像回读、显式文件差异、元数据、实际底包组合的策略编译及 AVB 链检查通过。
这些不等于实机压感或稳定性验收。Pro 点击/拖动的既有测试使用过 su 诊断服务；本次生产服务域配置尚未完成实机验收。
v15 在 Pro 鼠标模式内关闭额外振动只是诊断分支，实机曾再次复现方向停止，不能宣传为有效修复。
Android System Intelligence 的崩溃不在本次手写笔增量修改范围内；本包不能据此宣称修复该崩溃。
