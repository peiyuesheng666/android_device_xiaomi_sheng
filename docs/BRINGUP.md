# sheng 设备配置

设备树面向小米平板 6S Pro，硬件型号为 24018RPACC。启动、分区、HAL、输入、音频、显示、权限和应用配置集中在本目录，原厂驱动由 `vendor/xiaomi/sheng` 提供。

LineageOS 与 PixelOS 使用独立产品入口，共用硬件配置和内核输入。构建入口及命令见 [ROM 产品入口](ROM_COMPATIBILITY.md)。

准备源码时，应同时提供设备树、私有驱动、板级内核设备树、模块源码及固件输入。原厂固件保持原始内容，公共源码遵循目标 ROM 的清单。设备应用与随附特权权限放在 product。

分区大小依据本机布局配置。内核及模块必须来自匹配的构建输入，打包时校对依赖、符号和模块加载清单。固件在系统启动、首次挂载和 Recovery 中需要使用各自可达的路径。

首次构建使用对应 ROM 的完整产品目标。完整产物需要检查镜像大小、VINTF、SELinux、原生依赖和 AVB 链，再进行刷入与启动检查。切换 ROM 时使用独立输出目录，后续局部修复采用增量编译。

构建交换空间与原生暂存目录由 C 盘承载。存储配置见 [构建交换区配置](BUILD_SWAP_STORAGE.md)，依赖维护见 [源码策略](SOURCE_POLICY.md)。
