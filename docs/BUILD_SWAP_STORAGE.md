# 构建交换区配置

构建交换空间只能使用 C 盘承载的存储。E 盘可保存产物，禁止在 E 盘创建、启用或恢复交换文件。

WSL 的 `.wslconfig` 必须设置 `swap=0`，关闭自动交换盘。编译优先复用经过检查的原生交换文件；旧文件已清理时，构建入口通过明确的容量参数在 `/root/sheng-build.swap` 创建所需交换空间。不会扩容已有文件。发行版的 `ext4.vhdx` 位于 `C:\Users\Public\wsl\Ubuntu2204`。

`prepare_sheng_stylus_swap.py` 在构建前核对发行版的实际位置、WSL 配置与 `/proc/swaps`。默认交换分区、未经允许的交换文件、非 C 盘存储和指向其他挂载的链接都会阻止构建。内存配置工具也必须保留 `swap=0`，不能恢复旧的 E 盘交换配置。

`SHENG_BUILD_SWAP_GIB` 设置构建入口在缺少交换文件时申请的容量，默认 32 GiB。设为 0 禁止创建；此时必须已有符合条件的交换文件。创建前检查 C 盘余量，使用独占锁并完整分配文件，再格式化和启用。

构建和打包工具监控 Windows 提交额度与 C 盘剩余空间。低于保护线时停止当前任务并保留产物，默认保护线分别为 3 GiB 和 6 GiB。WSL 子进程的内存限制还需为虚拟机保留运行余量。

原生暂存目录位于 C 盘发行版内。经过内容、文件标签和 AVB 校验后，最终产物可通过工作区的 `artifacts` 目录发布到产物盘；这不会改变交换区位置。清理暂存文件前必须确认路径位于当前任务目录，且不存在符号链接越界。
