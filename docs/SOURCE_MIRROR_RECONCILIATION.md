# 源码镜像一致性

工作区设备树是构建镜像的来源。准备工具按功能目录同步源码，随后校验每个构建输入的文件内容与类型。

`prepare_sheng_pen_settings_product.py` 仅整理其负责的手写笔目录。过时的普通文件先复制到本次调用的独立备份目录，确认内容一致后再从镜像中移除；未知符号链接保留并使同步失败。

`verify_device_source_mirror.py` 默认检查设备根配置与主要构建输入。`--path` 限定功能范围，配合 `--reject-extra` 可拒绝镜像目录中多出的文件；被 Git 忽略但仍参与构建的生成输入也逐项比较。

严格检查应在编译或打包前进行。镜像检查只确定源码一致性，产物的 ABI、签名、分区布局及运行行为由各自构建和安装检查处理。
