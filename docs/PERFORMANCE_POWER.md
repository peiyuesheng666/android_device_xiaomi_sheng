# 性能与低功耗接口

LineageOS 和 PixelOS 共用本设备的内核性能接口及 Qualcomm perf 配置。
原厂配置来自 5.15，原始底子有过低功耗故障；迁移到 6.18 时需同时对照原厂
配置与已验证的 5.15 运行状态，核对资源编号、节点语义、CPU 拓扑、频率单位、
服务权限和状态通知。

`msm_performance` 的四个负载节点依赖真实 WALT core_ctl 通知。SoC 与 WALT
在同一次 modpost 中编译，消费者启用对应的模块声明；保留原始负载、集群
利用率和容量统计，以及每 25 个通知的汇总方式。不能将空通知订阅或恒定零
统计作为兼容接口。

post-boot 的 WALT 参数、调速器选择和低功耗初始化需要完整执行。性能提示
结束后需检查频率和 latency QoS 释放，息屏后检查深度空闲驻留及真实功耗。
不通过永久最高频率、关闭低功耗或跳过原厂服务来处理适配问题。

`tools/audit_sheng_perf_runtime.py` 只读采集当前安装的 perf XML、目标资源覆盖、
节点权限标签和电源状态。调用时显式指定 ADB 路径、设备序列号和新的输出目录。
该工具可用于两种 ROM；节点存在、主机 root 可读取或 ADB 活动下的短时采样
不能代替 HAL 域访问、性能提示效果和待机功耗验收。
