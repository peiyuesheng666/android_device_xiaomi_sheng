# sheng 设备树维护范围

设备适配代码集中在 `device/xiaomi/sheng`，通用硬件配置与 ROM 产品入口分开维护。公共依赖按 ROM 清单选取，原厂二进制通过提取清单管理。

维护工作覆盖显示、触摸、手写笔、键盘、音频、媒体编解码、网络、传感器、电源、指纹和 Recovery。应用统一安装到 product，特权权限随应用放在同一分区。两种 ROM 保留各自默认输入法；设备树不预装搜狗，不强制切换输入法，也不加入小米笔记。

键盘睡眠时背光反复亮灭列为待修项。先完成面板状态通知与键盘 MCU 睡眠／唤醒同步的源码、模块 ABI 和签名检查，再在实机验证熄屏稳定、实体键唤醒、键盘和触控板输入及重新连接；未完成成对模块的实机回归前不标记修复。

先收敛源码修复，使用静态检查和针对性编译，再对相关功能进行验证。集中修复完成后进行完整产品构建，检查安装布局、ABI、VINTF、SELinux 和 AVB 的一致性。

构建交换空间只允许使用 C 盘承载的存储。E 盘仅可保存产物，不能创建或启用交换空间。增量打包必须显式指定当前安装基线，并保留其余分区、文件标签和签名链。

人脸现场验证、相机及 AON 操作、手写笔按键续测暂缓。设备排查使用必要的日志和状态读取，不截图或录屏。

Markdown 用于功能、配置和使用说明。构建输出、运行日志、产物身份和待办状态保存在工作区 reports 的 JSON 或日志文件中。代码修改不自动提交或发布。
