# 设备接口集成

设备树以 BoardConfig、device.mk 和产品入口声明启动、分区、模块、服务与应用。接口实现集中在 `interfaces`，资源覆盖、属性、init 和 SELinux 配置随设备维护。

| 范围 | 配套配置 |
| --- | --- |
| 输入 | 触摸、手写笔和键盘服务，硬件身份、节点标签与输入恢复。 |
| 显示 | Composer、色彩控制、自动白平衡及笔输入显示请求。 |
| 音频与媒体 | 音频 HAL、Dolby、Codec2 工厂、解码后端和文件解析入口。 |
| 生物识别 | 指纹节点及原生人脸接口，传感器声明与凭据生命周期。 |
| 电源与连接 | 充电、传感器、Wi-Fi、蓝牙、定位和挂起唤醒接口。 |
| 启动 | 内核、模块依赖、Recovery、VINTF、SELinux 与 AVB 链。 |

新增应用统一进入 product，权限随应用放置。两种 ROM 保留各自默认输入法，设备树不预装搜狗、不强制切换输入法，也不加入小米笔记。目录说明见 [硬件适配索引](HARDWARE_STATUS.md)。

源码修复先使用静态检查和针对性构建，再对收敛后的组合进行完整产品构建。打包显式选择安装基线，核对分区、文件标签和签名链。交换空间要求见 [构建交换区配置](BUILD_SWAP_STORAGE.md)。

功能状态和构建输出保存在工作区 reports 的 JSON 或日志中；本文只维护配置关系。
