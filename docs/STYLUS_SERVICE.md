# 手写笔常驻服务

`ShengStylus` 位于 product，负责配件发现、GATT 会话、输入与显示协调、按键事件和吸附提示。`vendor.lineage.sheng.stylus-service` 位于 vendor，通过稳定 AIDL 接口 `IPenController/default` 管理触摸控制器和 hidraw 读取。

GATT 操作在单一 actor 中串行执行，回调绑定当前设备与会话。初始化依次处理双 ID、原厂参数、ready、时序应答和压力订阅。吸附、亮灭屏、断连及较晚到达的状态消息均由同一状态机裁决。

原生端仅接受匹配硬件身份和描述符的 Pro 压力报告，使用本机 THP 接口传递压力，保留真实 NVT 笔尖输入。服务在持有控制器连接时记录自己的资源归属，清理时只释放该会话持有的 ID 和状态。

`PenInputLease` 管理配件附带的输入节点，恢复记录同时保存 ID 与身份；`DisplayRateLease` 持有独立 Binder token，按取放和屏幕状态请求显示速率。会话结束时释放两者，不改写用户刷新率或息屏设置。

2026-11-15：充电 UEvent 和 DisplayManager 变化会提示 actor 立即重新读取真实吸附、亮屏及蓝牙状态，保留 500 ms 后备轮询；事件内容本身不能设置状态或绕过校验。PenWakeGate 持续观察屏幕亮灭，保持真实唤醒后 1000 ms 的保护；释放/重获刷新率请求不再重新计算亮屏时间，因此屏幕一直亮着时取笔不会重复等待一秒。实际刷新率范围检查、原生 DPMS 稳定保护和 MIPP 原厂应答流程均保留。84 项状态、手势及协议检查通过，用户已确认取笔响应、书写和挤压可用并要求保留此版。

非正常终止留下的原生控制器记录不能当作已释放资源。无法确认控制器归属时保留恢复标记，并要求设备重启后重新初始化，避免重复连接或错误释放。

充电信息与设置页共享解释逻辑。吸附提示显示当前型号、笔图、电量条和百分比，以动画进入和退出，仅支持上滑收起，不创建通知栏条目。按键分发使用当前笔的事件映射，输入框手写识别由用户选择的输入法提供。

产品同时声明应用权限、vendor 服务、VINTF 接口和 SELinux 标签。修改稳定接口时，应同步维护冻结定义、调用端与服务端。应用分区说明见 [设备应用布局](PRODUCT_APPS.md)。
