# 硬件故障定位

## 后续功能待办

- 2026-11-20 用户新增：键盘背光亮度控制，交互和实际灯光效果对齐官方系统。状态：待实现、待实机验证；后续对照官方系统确认亮度档位、调节入口和熄灯行为。不等同于已验收的键盘输入修复，当前不打断 Magisk 优先修复。

## 排查入口

| 范围 | 配置与排查入口 |
| --- | --- |
| 显示、刷新率与白平衡 | `interfaces/display`、Framework 资源覆盖，以及系统和 DRM 的文本状态。 |
| 触摸、手写笔与键盘 | `interfaces/input`，分别检查物理连接、服务状态和系统输入设备。 |
| 音频与蓝牙 | 音频策略、编解码器声明、原生依赖和实际协商结果。 |
| 传感器与电源 | 传感器注册、有效事件、节点访问权限和系统电源状态。 |
| 生物识别 | 服务声明、密钥命名空间和原有系统录入流程；现场操作单独安排。 |
| Recovery | `rootdir/recovery` 中的显示、触摸、存储与电池接口。 |

修复应保留独立功能的权限和现有设置。没有可靠数据源的电池日期、寿命等信息使用未知值或设备提供的范围。运行日志、构建身份和待办状态保存在工作区 reports 的结构化文件中。
