# 已停用：旧传感器坐标恢复工具

旧 Python / CMD / BAT 写入工具已从设备树删除，不得执行历史副本。
禁止为修复旋转改写 persist、传感器 registry 或校准矩阵；只允许在 HAL / 驱动运行期映射事件。
源码删除不代表实机遗留调用已清除，也不代表受损校准已恢复。以下仅为旧工具的历史说明，不再适用。

适用于 sheng（小米平板 6S Pro），用于撤销本设备树旧版本对传感器坐标系的转换。
不是通用校准工具，不包含其他平板的校准数据。

## 使用

1. 解压工具包。无需 Python，使用 Windows 自带 PowerShell；单独 BAT 在找不到 ADB 时会从 Google 官方下载。
2. 平板进入 TWRP，连接电脑。若 persist 尚未挂载，在 TWRP 挂载 persist。
3. 双击 `Restore-Xiaomi-Sensors.bat`。显示 `SUCCESS` 或 `Already restored` 后完成。
4. 按需要启动或刷回小米官方系统。工具不自动刷机、重启、清除或格式化 data。

必须在 Recovery 操作，脚本会拒绝在正常运行的系统里修改校准，以免与 SSC 的实时写入冲突。
如果缺少这台设备的 `.sheng-landscape-frame-v1.json` 原始记录，工具会停止；不会猜测出厂校准。
运行时仅连接一台平板。

## 保护措施与验证范围

- 写入前把涉及的原文件、旧记录和恢复事务备份到电脑 `sensor-backup-时间` 目录。
- 未发生后续校准的项目恢复为本机原始内容，包括方向叶节点的版本号。
- 后来更新的校准只做逆坐标变换，保留更新后的数值所代表的物理校准。
- 如果方向已恢复到官方坐标，不再转换该传感器的校准。
- 全部预检完成后才开始写入；每个文件先传到临时文件，核验 SHA-256、权限和标签，再原子替换。
- 中途断开后保留事务记录，可重新运行。遇到独立修改会停止，避免覆盖。
- 不删除 persist、不使用其他设备的校准，不写入 boot、vendor_boot 或 data。

已进行电脑副本测试；没有在平板上执行这个恢复脚本，也没有通过刷回官方系统验证旋转。
TWRP 格式化 data 后恢复的现象尚未完整复现，不能仅凭代码排查认定所有旋转异常都由这次迁移造成。
