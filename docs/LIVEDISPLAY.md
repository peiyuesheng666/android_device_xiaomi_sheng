# 显示色彩控制

显示菜单、RGB 调节、夜间模式和环境白平衡分别由系统颜色管理及设备显示接口协作处理。Settings 资源覆盖提供菜单名称与取值，Framework 资源覆盖提供可用模式；两者须保持对应。

`interfaces/display` 提供 composer、DRM 适配与色彩管理。原厂色彩库的接口布局由设备侧兼容层处理，内存所有权、容器寿命和虚函数布局应共同维护。不能只修请求入口而忽略最终硬件参数。

RGB 和夜间模式通过系统色彩变换工作。环境白平衡使用独立开关，受传感器有效数据、色彩模式及其他颜色变换限制，详细配置见 [自动白平衡](DISPLAY_WHITE_BALANCE.md)。

诊断使用系统状态、composer 缓存和 DRM PCC 属性对照。`ShengDrmColorProbe.c` 只查询属性，不读取屏幕像素或改变显示模式。
