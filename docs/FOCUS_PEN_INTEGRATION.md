# Focus Pen 接入

手写笔由 `interfaces/input/stylus` 的常驻应用、共享协议模块和 vendor 原生服务协作管理；`interfaces/input/pen` 提供设置页。两个应用安装在 product，特权权限与对应应用位于同一分区。

连接前校验配件的 Bluetooth PnP 来源、厂商、型号和设备地址。普通 Focus Pen 与 Pro 使用各自的初始化参数；Pro 专属状态命令和压力报告格式仅应用于匹配的型号。

应用串行处理 GATT 操作及回调，完成控制器 ID、参数、ready 和压力订阅的初始化。原生服务读取匹配的 hidraw 节点，将 Pro 的原始压力报告送入本机 THP 接口，笔尖坐标继续来自真实 NVT 输入节点。

取下且亮屏时，服务通过独立显示请求将可用速率限制到笔输入支持范围。请求不改写用户刷新率设置，吸附、结束会话或 Binder token 死亡时撤销。息屏、断连及迟到回调由会话状态机处理。

配件附带的键盘、鼠标和消费控制输入按硬件身份临时管理。输入恢复记录绑定设备身份，不能用复用后的输入 ID 恢复另一台设备。控制器、输入和显示请求必须随会话一起释放。

设置页提供型号、连接、电量及充电信息。吸附提示使用型号、笔图、电量条和百分比，带进出动画，通过上滑收起。输入框的手写识别由当前输入法提供，设备树保留 ROM 默认输入法与用户的选择。

协议和生命周期配置见 [常驻服务](STYLUS_SERVICE.md)，界面说明见 [手写笔设置](PEN_SETTINGS.md)，普通版协议说明见 [普通 Focus Pen](ORDINARY_FOCUS_PEN_OFFLINE.md)。
