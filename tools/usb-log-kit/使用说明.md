# USB 3 / DP 抓日志工具（Windows）

也收集充电协议、电流电压、充电限制和温度节点。测试充电请使用无线 ADB，保持原装充电器/线连接；记录电量与功率表读数。电池侧电流电压不等于充电器输入功率，双电芯设备的软件显示也可能有换算差异，不能只据此认定充电器功率。

解压整个压缩包后使用，不要直接在压缩包里运行。不需要安装 Python。

1. 平板打开开发者选项和 USB 调试，连接电脑，允许这台电脑调试。
2. 双击 `Start-Capture.cmd`。核对显示的设备信息后回车。
3. 出现 `Recording` 后开始复现：拔掉平板端线，等 5 秒重新插入；测试 MTP 文件传输或接电视。默认记录 180 秒，请尽早完成复现。
4. 完成后，将 `logs` 目录中新生成的 `usb-日期时间.zip` 发给维护者，并说明插拔的大概时间、电脑接口、线材、现象和 ROM/内核版本。

## 推荐先连接无线调试

DP 和外接 USB 设备会占用平板 USB-C 口，建议电脑、平板连接同一 Wi-Fi，使用系统自带“无线调试”。在本工具目录打开终端，依次执行：

```powershell
.\platform-tools\adb.exe pair 平板IP:配对端口
.\platform-tools\adb.exe connect 平板IP:连接端口
.\Start-Capture.cmd -Serial 平板IP:连接端口
```

配对端口来自“使用配对码配对设备”弹窗，连接端口来自无线调试主页面，两者通常不同。终端按提示输入配对码。无线连接成功后可拔掉电脑 USB 线，再运行抓取。多个 ADB 设备同时在线时，使用 `-Serial` 明确选择平板。工具不会自行配对、启用无线端口或改变网络设置。

仅通过 USB 调试也可使用。插拔期间 ADB 会断线，这段时间电脑无法实时读取；工具会继续等同一设备恢复，并读取仍留在内核缓冲区的日志。断线较久或无线端口变化时，需要重新连接并再抓一次。

## 内核权限

工具自动读取当前 ADB 权限可访问的内核和系统信息。若 `permissions.txt` / `kernel-*.txt` 显示 `Permission denied` 或 `Operation not permitted`，说明 ROM 限制了内核日志，不能把空日志当作“内核正常”。

如果 ROM 已支持 Root 调试，可自行启用后重跑；本工具不主动执行 `adb root`。如果装有 Magisk/KernelSU 并允许 shell 使用 root，可以执行：

```powershell
.\Start-Capture.cmd -UseSu
```

按平板提示授权。工具会先验证 su 是否可用；缺少 su 或未授权时，自动回退到当前 ADB 权限继续读取，并在 events.json 中标注。此选项仅对内核/sysfs读取调用 `su -c`；没有 root 时仍会收集普通权限可用的信息，不会尝试提权漏洞。

## 可选参数与内容

```powershell
.\Start-Capture.cmd -Seconds 300
.\Start-Capture.cmd -Serial 平板IP:连接端口 -UseSu -Bugreport
```

记录包含：持续 logcat、可用的持续/定期 dmesg、USB 主机与设备实际速度及最高能力、Type-C/供电/数据角色、DWC3/PHY 电源状态、gadget、USB 服务、DRM 接口/显示模式/EDID、SurfaceFlinger、音频服务、崩溃缓冲区，以及电脑 USB/MTP PnP 状态。`commands.json` 记录命令返回值和超时，`events.json` 记录电脑时间、断线与恢复。

`-Bugreport` 会额外生成 Android 完整问题报告，最长等待 5 分钟。默认不开启。工具不截图或录屏，不清除原日志，不改 USB 配置、不重启、不刷机、不挂载 debugfs。仅在 `/data/local/tmp` 上传本次只读探针，结束连接正常时删除。

`current_speed` 是平板作为 USB 设备连接电脑时的实际速度；`maximum_speed` 只是能力。平板接外设时，查看 `/sys/bus/usb/devices/*/speed`：480 是 USB 2.0 High-Speed，5000/10000 是 SuperSpeed。USB3 集线器上的 USB2 设备仍可能显示 480，不能只看任意一个节点就认定整条链路降速。DP 还要结合链路训练、通道数和速率日志判断。

日志可能含设备序列号、网络地址/名称、应用活动，建议私发维护者，公开前先检查。有限权限或 ROM 未输出训练细节时，日志不保证能唯一定位到线材、接口、PHY 或驱动。
